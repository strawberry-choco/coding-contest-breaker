# Level 1 — Sum (worked example)

This is a tiny synthetic level used as a worked example and as the fixture for
the repo's tests. It is `kind: exact`.

## Input

- Line 1: an integer `N` (1 ≤ N ≤ 1000).
- Line 2: `N` integers separated by spaces.

## Output

- A single line: the sum of the `N` integers.

## Example

Input:
```
3
1 2 3
```
Output:
```
6
```
